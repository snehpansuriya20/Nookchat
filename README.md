# 💬 MainHackathon — Chat Website

A web-based chatting application built using HTML, CSS, and JavaScript, designed to make communication simple and interactive.

## 🚀 Features

- 👤 User authentication interface
- 💬 One-to-one messaging
- 👥 Group conversations
- 📢 Broadcast messaging
- ✏️ Edit messages
- 🗑️ Delete messages
- 📌 Pin important messages
- 📎 File sharing
- 🎨 Interactive and user-friendly interface

*Features depend on the current implementation and backend integration.*

## 🛠️ Technologies Used

- HTML
- Git and GitHub

## 📁 Project Structure

```text
mainhackathon/
├── index.html   # Main page
├── chat.html    # Chat interface
├── auth.js      # Authentication logic
└── README.md    # Project documentation
```

## ⚙️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/snehpansuriya20/mainhackathon.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

4. Explore the website and its available features.

**Note:** If the application requires a backend or database, configure and start those services before using features that depend on them.

## 🎯 Project Objective

The objective of this project is to build an interactive messaging platform while learning web development, frontend design, JavaScript, and collaborative software development.
